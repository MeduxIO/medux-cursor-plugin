# Medux plugin for Cursor

Connects Cursor to the [Medux](https://medux.io) remote MCP server for AI media generation and editing.

## Setup
1. Create an API key (`sk-medux-...`) in your Medux account.
2. Export it before launching Cursor:
   ```bash
   export MEDUX_API_KEY=sk-medux-...
   ```
3. Install the plugin from the Cursor Marketplace, then restart Cursor.

MCP endpoint: `https://medux.io/api/mcp/v1`
